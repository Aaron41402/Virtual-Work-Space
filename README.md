# Task Hero

This repository contains the source code for **[TaskHero](https://mytaskhero.vercel.app/)**, an AI-powered virtual workspace application designed to help you efficiently manage your schedule and tasks.

## Live Demo

Visit the live application at:

👉 [https://mytaskhero.vercel.app/](https://mytaskhero.vercel.app/)

## How Task Hero Works
Task Hero turns productivity into a game. Complete tasks, level up with AI assistance, and stay focused with your capybara companion. Make work fun in our pixel art world!

## Meet Your Productivity Companion - Capybara!
Work with your capybara friend using the Pomodoro technique. Stay focused, take breaks, and boost productivity!

- Customized with fun skins and outfits
- Take timed breaks together
- Boost productivity with a furry friend

## Meet Emi, Your AI Companion
Emi helps you stay on track and maximize your potential every day.

- Tracks your schedule and tasks
- Analyzes productivity patterns
- Provides timely reminders and tips
- Answers questions with AI

## Technologies Used

- **Next.js** – Frontend framework with server-side rendering and static site generation.
- **Tailwind CSS** – Utility-first framework for rapid UI development.
- **MongoDB** – NoSQL database to store user and task data.
- **NextAuth.js** – Robust authentication solution for Next.js applications.
- **Google Gemini** - AI-powered assistant integration for enhanced user interactions.

## Installation

Follow these steps to run the app locally:

1. **Clone the repository:**

```bash
git clone https://github.com/Aaron41402/Virtual-Work-Space.git
```

2. **Navigate to the project folder:**

```bash
cd Virtual-Work-Space
```

3. **Install dependencies:**

```bash
npm install
# or
yarn install
```

4. **Set environment variables:**

Create a `.env` file in the root directory and set your environment variables:

```env
MONGO_URI=your_mongodb_connection_string
AUTH_SECRET=your_auth_secret
GOOGLE_ID=your_google_id
GOOGLE_SECRET=your_google_auth_secret
GEMINI_API_KEY=your_gemini_api_key
```

5. **Run the development server:**

```bash
npm run dev
# or
yarn dev
```

6. **Open the application:**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
